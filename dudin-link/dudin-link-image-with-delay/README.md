# ImageLink with delay

It synchronizes the image  with **delay**, similar to *ImageLink* builtin plugin but not immediate.

### Version 1.2.0 — 04.08.2026

* add a checkbox to disable syncing when the source container is effectively hidden — at least one of the parents is inactive, and the scritpt supposed to not work 

### Version 1.1.0 — 28.07.2026

* three modes: immediate, by delay, by button

### Version 1.0.0 — 28.07.2026

* arbitrary amount of targets — just change `TARGETS_AMOUNT` variable in the script
* you can define the delay in frames
